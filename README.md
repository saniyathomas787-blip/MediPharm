# MediPharm – Pharmacy/Healthcare Management System

MediPharm is a web-based pharmacy and healthcare management system developed using React and Vite.

## Features

- Admin Login
- Admin Dashboard
- Medicine Management
- Pharmacy Management
- Pharmacist Management
- Reports Management
- User-friendly interface

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML
- CSS

## Installation

1. Clone the repository
2. Open the project folder
3. Install dependencies:

npm install

4. Start the development server:

npm run dev
